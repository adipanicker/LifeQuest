# LifeQuest ⚔️

A gamified productivity app where completing todos earns you XP, levels you up, and builds streaks.

## Features

- JWT Authentication
- Todo management with XP rewards
- Level up system (every 100 XP)
- Daily streak tracking
- Quests history with date grouping
- Resurrect past tasks back to today

## Tech Stack

**Frontend:** React, Vite, Tailwind CSS  
**Backend:** Node.js, Express  
**Database:** PostgreSQL (Supabase)  
**Deployment:** Vercel (frontend), Render (backend)
